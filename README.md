## 📦 项目列表
- **Pomodoro_Tool 番茄钟工具**
  是基于PyQt5开发的桌面倒计时工具，深色/浅色界面，支持自定义工作、休息时长、计时结束弹窗提醒、统计表导出，由糖纸工作室原创

这是一款简洁好用的番茄计时器，专注学习、工作计时。
